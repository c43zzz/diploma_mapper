# Mapper-анализ активаций Gemma-2

Этот репозиторий содержит код эксперимента по анализу активаций языковой модели с помощью алгоритма Mapper из топологического анализа данных.

Цель эксперимента — построить Mapper-граф по активациям слов, посчитать статистики для каждой ноды и визуализировать результат в интерактивном HTML-графе.

## Что делает код

Пайплайн:

1. загружает активации модели, метаданные и SAE-активации;
2. строит низкоразмерную проекцию через UMAP или PCA;
3. строит Mapper-граф с помощью KeplerMapper и DBSCAN;
4. считает статистики по нодам;
5. генерирует промпты для LLM-разметки тем нод;
6. импортирует ответы модели, если они есть;
7. создает интерактивную HTML-визуализацию графа.

## Структура
.
─ mapper_experiment_config.py          # основной файл запуска эксперимента  
─ mapper_node_stats.py                 # построение Mapper-графа и расчет статистик  
─ mapper_node_topics.py                # генерация промптов и импорт тем нод  
─ mapper_node_hover_kepler_native.py   # HTML-визуализация графа  
─ README.md
